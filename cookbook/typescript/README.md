# TypeScript cookbook

Examples for [`@stat-api/client`](https://www.npmjs.com/package/@stat-api/client) (v0.3.1).

## Run

```sh
npm install
export STAT_API_KEY=...
npx tsx src/nba-hello-stat-api.ts
```

Each file in `src/` is a standalone program that reads the API key from
`STAT_API_KEY`.

## NFL sim tutorial (beta)

The 5 recipes of the NFL sim tutorial are in this folder, for example `src/nfl-sim-summary.ts`. Read [the tutorial](../nfl-sim/README.md) first.
