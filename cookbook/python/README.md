# Python cookbook

Examples for [`statapi`](https://pypi.org/project/statapi/) (v0.3.0).

## Run

```sh
pip install -r requirements.txt
export STAT_API_KEY=...
python nba_hello_stat_api.py
```

## NFL sim tutorial (beta)

The 5 recipes of the NFL sim tutorial are in this folder, for example `nfl_sim_summary.py`. Read [the tutorial](../nfl-sim/README.md) first.
